# PR-SIM 디자인 기준

화면 디자인의 기준 문서는 [screens/draft/DESIGN.md](./screens/draft/DESIGN.md)입니다.

모노크롬은 로고·배경·카드·버튼·텍스트 등 UI 요소에 적용합니다. **심사위원 이미지, 발표자 카메라 영상, 발표 슬라이드는 컬러로 표시합니다.** 작은 인물 썸네일까지 같은 기준을 적용하고, 업로드한 PDF의 원본 색상을 보존합니다. 화면 전체에 흑백 필터를 적용하지 않습니다.

수정된 시안은 [화면 시안 목록](./screens/draft/README.md)에서 확인할 수 있습니다.
