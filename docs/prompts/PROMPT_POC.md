# PoC (Proof Of Concept)

'PR-SIM' 웹앱을 만드는 에이전트 오케스트레이터다. 본격적인 개발을 하기 전에 PoC(Proof Of Concept) 를 해서 HIL(Human In the Loop)를 한>다. 아래 '###' 항목을 각각의 에이전트를 사용해서 구현을한다. PR-SIM은 웹앱이기 때문에 웹으로 확인할 수 있어야한다. 멀티에이전트 개발 >내용은 관측을 할 수 있어야한다. .env 에 개발을 위한 KEY들이 모두 있다. 전체 PoC는 완성 후 HIL을 하기 전까지 나에게 물어보지 말고 무중>단으로 진행한다.

## PoC 1 — UI

위치: `pocs/ui`

- `docs/sreens/drafts`의 디자인을 기준으로 화면 구현
- 실제 이미지와 화면 구성을 최대한 보존
- 각 화면을 브라우저에서 직접 확인
- 데스크톱 목업 및 모바일 화면 검증
- Claude CLI로 원본 이미지와 스크린샷 비교

## PoC 2 — STT/TTS

위치: `pocs/stt-tts`

- Gemini API를 활용한 음성 전사
- 문장 단위 STT 결과 표시
- Gemini TTS 음성 생성 및 재생
- 심사위원 성별, 연령, 성격에 따른 음성 차별화
- 브라우저 마이크 권한 및 실제 발화 테스트

성별·연령·성격에 따른 음성 조정은 API가 실제 지원하는 범위에서 구현한다.

음성 기능은 공식 지원 방식과 지연시간을 검증한다. 실시간 스트리밍이 불가능하다면 문장 단위 처리로 구현하고 제약을 기록한다.

## PoC 3 — Context to Wiki

위치: `pocs/wiki`

사용자가 업로드한 PDF를 LLM Wiki로 변환한다.

- PDF 원문에서 페이지별 내용 추출
- 문서별 목차와 핵심 요약 생성
- 주제·개념·근거 간 연결
- 원본 페이지 번호와 출처 보존
- 여러 문서 사이의 연결과 충돌 표시
- 필요한 문서 부분만 선택적으로 AI 컨텍스트에 주입

Karpathy의 LLM Wiki 패턴을 적용하여 원문, Wiki, 구성 규칙을 분리한다.

대용량 PDF는 분할 처리하고 필요에 따라 Wiki를 점진적으로 구축한다.

처음부터 Vector DB나 별도 RAG 서버를 도입하지 않는다. 검색 품질에 실제 문제가 확인될 때만 추가한다.

**사용자 업로드 문서의 Wiki와 `docs/wiki/` 개발 문서 위키는 서로 다른 데이터다.**

사용자 PDF와 생성 Wiki는 세션별로 격리하고, 민감한 제안자료가 Git에 포함되지 않도록 한다.

## PoC 4 — 심사위원 생성

위치: `pocs/judge`

- OpenAI API를 통한 실사 얼굴 이미지 생성
- 입력은 친절함, 빡셈, 공격적 세 가지
- 심사위원마다 서로 다른 인물 생성
- 외형의 다양성 확보
- 생성 이미지 표시 및 재사용

실존 인물을 복제하지 않으며, 페르소나의 차이는 표정·분위기·연출과 실제 질문 태도로 표현한다.

## PoC 5 — Slide View

위치: `pocs/slide`

- PDF 업로드
- PDF 페이지 렌더링
- 좌우 스와이프
- 이전/다음 페이지 이동
- 현재 페이지 및 전체 페이지 표시
- 모바일 터치와 데스크톱 마우스 테스트

## PoC 6 — 심사 질문

위치: `pocs/question`

다음 데이터를 활용하여 질문을 생성한다.

- 사용자의 발표 STT
- 발표자료 Wiki
- 제안자료 Wiki
- 발표 상황
- 심사위원 페르소나

페르소나별 질문 스타일:

- 친절함: 이해를 돕는 확인 질문
- 빡셈: 근거와 실행 가능성을 집요하게 검증
- 공격적: 논리적 허점과 모순에 대한 압박 질문

각 질문에 관련 문서와 근거를 연결한다.

페르소나는 질문의 어조와 난도에 영향을 주되 근거를 왜곡하거나 없는 사실을 만들어서는 안 된다.

## PoC 7 — 리포트

위치: `pocs/report`

- 발표 STT 분석
- 핵심 내용 전달 여부
- 심사 질문의 적절성
- 답변의 근거와 타당성
- 발표자료와 제안자료의 일관성
- 구체적인 개선 제안 생성

평가 결과는 실제 발표 내용과 업로드 문서에 근거해야 한다.

분석할 수 없는 항목은 추정 점수를 부여하지 않고 평가 불가로 표시한다.
