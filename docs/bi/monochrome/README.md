# PR·SIM — Monochrome / TURN

발표와 반복 연습을 하나의 둥근 P형 심볼로 표현한 흑백 로고 시안입니다. 안쪽의 굽은 여백은 발화가 되돌아오는 흐름을 암시합니다.

## 디자인 방향

- `../ref-sel/`에서는 부드러운 모서리, 단순한 인상, 굵은 산세리프의 조합을 참고했습니다.
- 기존의 겹친 슬라이드 패널·원근·블루/시안 대신, 하나의 덩어리와 곡선 여백으로 새로운 실루엣을 구성했습니다.
- `../../screens/draft/DESIGN.md`의 넓은 흰 바탕, Ink 중심 대비, 둥근 카드와 어울리게 설계했습니다. 해당 문서의 임시 블루/시안 심볼 규정보다 이번 요청의 흑백 방향을 우선합니다.
- 기본 조합은 검정 심볼 + PR·SIM 워드마크이며, 검은 면에서는 흰색으로 반전합니다.

## 파일

- [identity-board.png](identity-board.png): 가로형 로고, 반전 로고, 앱 아이콘 적용을 담은 검토 보드.
- [symbol-transparent.png](symbol-transparent.png): 투명 배경의 검정 심볼 단독 PNG.
- [prompts.json](prompts.json): 생성에 사용한 프롬프트 원문.

## 제작 및 사용

내장 image_gen으로 제작한 래스터 시안입니다. 검토 보드와 심볼 추출 이미지는 생성 결과이므로 미세한 윤곽 차이가 있을 수 있습니다. 최종 구현용 벡터 원본이나 폰트 아웃라인은 포함하지 않습니다.

기준 색상은 Ink `#111111`, White `#FFFFFF`이며, 보조 적용 면만 `#F5F5F5`입니다. 이미지 생성 과정에서 미세한 톤 차이가 생길 수 있습니다. 심볼 주변에는 심볼 너비의 약 1/4 이상 여백을 확보합니다. 작은 크기 적용 시 안쪽 여백의 가독성을 확인합니다.

기존 BI 시안과 화면 파일은 유지하며, 이 폴더를 별도의 신규 방향으로 추가했습니다.
