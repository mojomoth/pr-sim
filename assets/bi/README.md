# PR·SIM 확정 BI 에셋

브랜드 결정과 사용 기준은 [위키](../../docs/wiki/brand-identity.md)를 따릅니다.

- `identity-board.png`: 확정 원본 사본.
- `lockup-light.png`, `lockup-dark.png`: 배경 포함 가로 로고.
- `lockup-black.png`, `lockup-white.png`: 투명 배경 가로 로고.
- `symbol-black.png`, `symbol-white.png`: 투명 배경 심볼.
- `wordmark-black.png`, `wordmark-white.png`: 투명 배경 워드마크.
- `app-icon.png`: 라운드 타일 바깥을 투명 처리한 앱 아이콘.
- `manifest.json`: 원본 좌표, 픽셀 크기, 처리 기록.
- `extract.py`: 확정 보드에서 PNG 에셋을 분할하는 스크립트.

투명 배경 흑백 쌍은 같은 기본형 윤곽을 사용합니다. 모든 에셋은 래스터 PNG입니다.
